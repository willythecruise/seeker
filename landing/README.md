# Seeker landing page

A responsive React/Vite landing page for **Seeker**, a timed testing and interview-preparation platform for software engineers.

## Run locally

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
npm run preview
```

## Included

- Scenic, image-led hero using the supplied artwork
- Custom Geist and Geist Mono fonts bundled locally
- Responsive desktop, tablet, and mobile layouts
- Animated SVG timers, skill radar, contours, rings, and morphing paths
- Interactive engineering path tabs
- Functional timed sample-test modal with answer feedback
- Sticky responsive navigation and mobile menu
- Results dashboard, social proof, closing CTA, and email signup states
- Reduced-motion support and keyboard-dismissable modal

All visual assets needed by the page are stored in `public/`; there are no runtime CDN dependencies.
